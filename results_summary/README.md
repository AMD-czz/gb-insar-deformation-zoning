# Archived performance results

The CSV preserves all nine archived trials (three methods, three runs, single thread, rotated order). These are computational performance metadata, not displacement observations. Medians of total_wall_s: physical 3D 3.065941 s, single-reference DTW 21.292468 s, PCA 4.310470 s. The original measurement includes proprietary raw-file reading/decoding. This public package does not include that component, so its synthetic demo cannot reproduce those wall-clock values.

No full-field labels, trained mine models, pixel features, acquisition files, ground-radar mine displacement curves or experimental data caches are redistributed. Tables with additional mine-derived metrics are not silently treated as unrestricted data.
