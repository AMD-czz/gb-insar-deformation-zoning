# Third-party components

No third-party source trees or binaries are vendored. NumPy, SciPy, scikit-learn, tslearn, Numba, h5py and threadpoolctl are installed as external dependencies under their own licenses. The proprietary radar protocol and decoder are expressly excluded by the data provider. SARscape, Tianditu imagery, article PDFs and commercial components are not redistributed.

The analysis code in this release is a portable refactoring of the authors' analysis equations/functions, with generic input/configuration interfaces. It is not a wholesale copy of a historical GUI project. Software availability does not imply access to the restricted mine observations.
